# Contoso SupportHub X1 Support Policy

**Scope:** This document defines the fictional support process and escalation rules for SupportHub X1.

**Last reviewed:** 2026-08-17

Support requests should include the observed error code, the actions already taken, and the device enrollment state when known.

For error E17, first restart the device, refresh the enrollment token, and retry the operation. Escalate the request when E17 persists after two retries.
