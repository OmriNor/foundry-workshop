# Contoso SupportHub X1 Product Overview

**Scope:** This document describes the fictional Contoso SupportHub X1 and its service tiers.

**Last reviewed:** 2026-08-17

Contoso SupportHub X1 is a fictional device-management hub for small support teams. It supports device enrollment, service requests, and status reporting.

Premium support is available 24x7. Standard support is available Monday-Friday, 08:00-18:00 local time.
