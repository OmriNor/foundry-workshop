# Code and SDK Workshop

Complete this workshop after finishing the [Portal Workshop](../portal-labs/README.md).
The notebooks recreate the same support-agent capabilities through the Python SDK.
They are independent from the portal agent and automatically create resources under
the `<PARTICIPANT_ID>-ws-...` prefix.

1. [Lab 1: Create the Support Agent](01-create-agent/create-agent.ipynb)
2. [Lab 2: Ground the Support Agent with Files](02-file-grounding/file-grounding.ipynb)
3. [Lab 3: Add an MCP Tool](03-mcp-tools/mcp-tools.ipynb)
4. [Lab 4: Combine Local Functions and Web Search](04-multi-tools/multi-tools.ipynb)

Before opening a notebook, select this repository's `.venv` Python 3.11 interpreter
as its kernel. See [kernel selection](../../README.md#select-the-python-interpreter-and-notebook-kernel)
for the Visual Studio Code steps.
