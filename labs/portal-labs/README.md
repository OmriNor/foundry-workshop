# Portal Workshop

Complete this workshop from start to finish in the Microsoft Foundry portal. You will
create one support agent, add grounding and an MCP tool, then evaluate that same agent.

Before you begin, complete the environment setup and local check in the repository
[README](../../README.md).

1. [Lab 1: Create the Support Agent](01-create-agent/README.md)
2. [Lab 2: Ground the Support Agent with Files](02-file-grounding/README.md)
3. [Lab 3: Add an MCP Tool](03-mcp-tools/README.md)
4. [Lab 4: Evaluate the Enhanced Agent](04-evaluation/README.md)

Portal resources use your normal `<PARTICIPANT_ID>-...` prefix. After completing Lab 4,
continue to the [Code and SDK Workshop](../code-labs/README.md).
